# 🚀 CareerPrep AI

**CareerPrep AI** is an all-in-one interview preparation and career-readiness platform designed to help students, freshers, and job seekers prepare for technical interviews, HR rounds, and software development roles across different technologies and domains.

The application combines an extensive interview question bank, customizable practice sessions, performance tracking, revision tools, and resume-to-job-description analysis to help users prepare for their career goals.

🌐 **Live Demo:** [CareerPrep AI](https://shivamtripathi78.github.io/CareerPrep-AI/)

---

## ✨ Key Features

### 📚 Comprehensive Interview Preparation

* **Multi-Domain Question Bank:** Practice questions across programming, software development, technical subjects, and HR interviews.
* **Multiple Technology Areas:** Prepare for interviews involving different programming languages, frameworks, tools, and technologies.
* **Role-Oriented Preparation:** Build knowledge relevant to different software development and technology career paths.
* **Company Interview Preparation:** Use subject-based practice to strengthen your readiness for technical recruitment processes.
* **Difficulty-Based Practice:** Choose questions according to your preparation level.
* **Customizable Quizzes:** Select relevant categories and difficulty levels for focused practice.
* **Answer Review:** Review answers after attempting questions and identify areas that need improvement.

### 🎯 Personalized Practice and Revision

* **Question Bookmarks:** Save important questions for later revision.
* **Quiz History:** Review previous attempts and revisit your preparation activity.
* **Progress Tracking:** Monitor performance and identify topics that require additional practice.
* **Revision Support:** Return to saved questions and previously attempted material.
* **Flexible Learning:** Practice according to your target role, technology interests, and learning needs.

### 📄 Resume Analyzer

* **PDF Resume Extraction:** Extract text from uploaded resume PDFs.
* **Job Description Matching:** Compare resume content against a target job description.
* **Matched Skills:** Identify skills in your resume that correspond to the job requirements.
* **Missing Skills Identification:** Highlight relevant skills mentioned in the job description but not detected in your resume.
* **ATS-Style Score Estimate:** Generate a rule-based estimate of resume relevance.
* **Improvement Recommendations:** Receive suggestions based on the resume and job description comparison.

### 📊 Performance and Progress

* Track quiz activity and review previous attempts.
* Identify strengths and areas that need improvement.
* Use bookmarks and revision tools to reinforce important concepts.
* Combine interview practice with resume preparation in one application.

## 🚀 Getting Started

### Prerequisites

Install the following tools:

* [Flutter SDK](https://docs.flutter.dev/get-started/install)
* [Git](https://git-scm.com/)
* [Visual Studio Code](https://code.visualstudio.com/) (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Shivamtripathi78/CareerPrep-AI.git
```

**2. Navigate to the project folder**

```bash
cd CareerPrep-AI
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application in Chrome**

```bash
flutter run -d chrome
```

### Build the Web Application

```bash
flutter build web --release
```

The production build will be generated in the `build/web` directory.

## 📌 Important Notes

* Resume matching and ATS-style scores are estimates generated using implemented matching rules; they are not official ATS evaluations.
* Resume recommendations depend on the information extracted from the PDF and the job description provided.
* Interview preparation content is intended to support learning and practice, not guarantee recruitment outcomes.
* Available technologies, subjects, and roles depend on the question bank included in the current application version.
