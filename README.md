# CareerPrep AI 🚀

**An interactive interview preparation and resume analysis platform built with Flutter.**

CareerPrep AI helps students and aspiring developers prepare for technical interviews, practice programming concepts, track performance, and improve their resumes.

🌐 **[Live Demo](https://shivamtripathi78.github.io/CareerPrep-AI/)** | 💻 **[GitHub Repository](https://github.com/Shivamtripathi78/CareerPrep-AI)**

## ✨ Features

* **Interview Question Bank:** 100 questions across Flutter, Dart, Programming, and HR.
* **Interactive Quizzes:** Customizable quizzes with difficulty selection, scoring, and answer explanations.
* **Bookmarks & Revision:** Save questions and revisit missed answers.
* **Performance Analytics:** Track quiz history, scores, and weak areas.
* **Personalized Practice:** Focus on topics that need improvement.
* **Resume Analyzer:** Compare resume content with job descriptions, identify missing keywords, and receive improvement suggestions.
* **Resume Checklist:** Review essential resume content.
* **Local Data Persistence:** Save supported progress and preferences.
* **Responsive UI:** Built with Flutter and Material Design 3.

## 🚀 Getting Started

**Prerequisites:** Flutter SDK, Dart SDK, Git, and a supported browser.

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/CareerPrep-AI.git
cd CareerPrep-AI
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run -d chrome
```

Build for web:

```bash
flutter build web --release
```

## 🧪 Testing

Run the following commands before submitting changes:

```bash
dart format lib test
flutter analyze
flutter test
```

## 🌐 Deployment

The application is deployed through GitHub Pages, with GitHub Actions configured to run quality checks and build and deploy the web application.

**Live Application:** https://shivamtripathi78.github.io/CareerPrep-AI/

## 🔒 Important Notes

* Resume analysis currently uses local, rule-based matching.
* The ATS-style score is an estimate, not an actual ATS result.
* The optional Python backend is not automatically connected to the Flutter application.
